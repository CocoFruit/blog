# 2026 Internship Updates

This folder contains weekly updates from the 2026 summer internship.

## Adding a New Week

Create a file named `weekN.md` with the following format:

```markdown
---
title: Week N
week: N
slug: weekN
photos:
  - /assets/images/week_2026_N_1.jpg
  - /assets/images/week_2026_N_2.jpg
---

Your week summary here...
```

Photos are optional. If you don't have photos for a week, just omit the `photos` field.
