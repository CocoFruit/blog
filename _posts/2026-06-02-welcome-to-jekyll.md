This is a sample blog post to demonstrate how Jekyll works. You can write posts in Markdown and they'll automatically be converted to HTML with your site's styling.

## Why Jekyll?

Jekyll is a simple, static site generator that's perfect for blogs and personal sites. It's:

- **Low-tech**: No databases, just files
- **Fast**: Static HTML loads instantly
- **Easy to maintain**: Write in Markdown
- **Git-friendly**: Version control everything

## Writing Posts

Create a file in `_posts/` with the format `YYYY-MM-DD-title.md`, add some front matter (the stuff between the `---` lines), and write your content in Markdown.

That's it! Jekyll handles the rest.
